# Mobile access without the App Stores (Expo Go / side-loaded APK)

**Decision (owner, 2026-10):** the product is **web-first**. The Expo mobile app is
NOT published to Google Play or the Apple App Store. Instead it runs through
**Expo Go** for development/preview, or as a **side-loaded APK** for close-to-native
distribution (Android only; iOS remains Expo Go for the foreseeable future).

This keeps the project free of Apple/Google developer accounts, store review,
app-store fees, and annual fees.

---

## 1. Option A — Expo Go (fastest, no build)

The app is a standard Expo SDK ~58 project, so it opens directly in Expo Go.

```bash
cd backend && python -m uvicorn app.main:app --port 8000 &
cd mobile
npx expo start
```

A QR code appears in the terminal. Scan it with the **Expo Go** app
(iOS/Android) on a phone on the same network. The mobile app points at the API
via `EXPO_PUBLIC_API_BASE_URL` (default `http://localhost:8000/api/v1`). For an
on-lan device set:

```bash
EXPO_PUBLIC_API_BASE_URL=http://<your-lan-ip>:8000/api/v1 npx expo start
```

Notes:
- Expo Go includes only the bundled native modules; everything the app uses
  (`expo-notifications`, `expo-secure-store`, `expo-constants`, vector-icons,
  svg) is Expo Go-compatible.
- No build, no credentials, no store. Ideal for demos, reviewers, and sales calls.

## 2. Option B — side-loaded Android APK (no Google Play)

`npx expo export --platform android` (or `expo export`) produces a self-contained
bundle plus the JS. For an installable APK without EAS, the standard route is an
Android Studio release build:

1. `cd mobile`
2. `npx expo run:android --variant release`
   (requires Android SDK; the `android/` dir is generated by Expo CNG — do not
   hand-edit it)
3. Grab the APK from
   `android/app/build/outputs/apk/release/app-release.apk`
4. Share the file directly (WhatsApp/AirDrop/drive). The phone must allow
   "install from unknown sources" — this is normal for side-loaded apps.

> Alternative (no Android Studio): `npx eas build --profile preview --platform android`
> produces an Expo-hosted installable APK with free tier, but this still pulls in an
> Expo account; that is optional and owner-approved only.

## 3. What we deliberately do NOT do

- No Google Play listing or updates.
- No Apple App Store / TestFlight.
- No app-store review process, tax forms, or developer-account fees.
